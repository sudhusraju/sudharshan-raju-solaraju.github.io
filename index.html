1. The Business Problem

Challenge: The VP of Sales at a mid-sized manufacturing firm faced declining revenue visibility. Regional managers submitted conflicting Excel reports, sales data was scattered across multiple Excel workbooks and an on-premise SQL Server database. Key questions remained unanswered: Which products are truly profitable? Why did the Western region miss targets for three consecutive months? Are we losing market share to competitors?

Objective: Build a single source of truth that provides real-time visibility into sales performance, forecasts trends, and enables drill-down from executive summary to individual transactions using only Excel and SQL data sources.

3. Data Cleaning with Power Query

Before building the model, raw data from Excel and SQL required extensive cleaning using Power Query Editor :

Standardize Region Names

"North Region" vs "NORTH" vs "North Region" → unified as "North" using Replace Values and Trim.

Fix Data Types

OrderDate column converted from Text to Date; SalesAmount cleaned of currency symbols and set to Decimal.

Remove Duplicates

Identified 1,247 duplicate invoice rows using "Remove Duplicates" on InvoiceID + LineItem.

Drop Unused Columns

Removed 20+ irrelevant columns (internal flags, deprecated fields) → model size reduced by 40%.

Power Query M Code Snippet (Data Cleaning):

// Standardize Region Names from Excel files
Table.ReplaceValue(#"Previous Step","north","North",Replacer.ReplaceText,{"Region"})
// Remove duplicates from SQL Orders table
Table.Distinct(#"SQL_Orders", {"OrderID", "ProductID"})
// Filter out cancelled orders
Table.SelectRows(#"Merged Data", each [Status] = "Completed")
// Trim whitespace in Customer Names
Table.TransformColumns(#"Previous", {{"CustomerName", Text.Trim, type text}})

Dimension Tables

5. Advanced DAX Calculations

Key business measures created using DAX (Data Analysis Expressions) :

📈 Total Sales

Total Sales = SUMX(Fact_Sales, Fact_Sales[Quantity] * Fact_Sales[UnitPrice])

📊 YoY Growth %

YoY Growth =
VAR CurrentSales = [Total Sales]
VAR PreviousSales = CALCULATE([Total Sales], SAMEPERIODLASTYEAR(Dim_Date[Date]))
RETURN DIVIDE(CurrentSales - PreviousSales, PreviousSales)

🎯 Sales vs Target

Sales vs Target = DIVIDE([Total Sales], SUM(Targets[TargetAmount]), 0)

🏆 Top Product by Revenue

Top Product = TOPN(1, VALUES(Product[ProductName]), [Total Sales])

Additional measures: YTD Sales, Moving Average (3 months), Profit Margin %, Customer Lifetime Value (CLV).

7. Key Insights Discovered
  • 📉 Western Region underperformance: 18% below target due to 2 underperforming sales reps (identified via drill-through). Action: Performance improvement plan implemented → +12% in next quarter.
  • 🏆 Product Insight: "Premium Series X" contributes 34% of total profit despite only 12% of volume. Recommendation: Increase marketing spend by 20%.
  • 📅 Seasonal Pattern: Sales dip every March (inventory transition from Excel tracking). Recommendation: Shift promotions to February → resulted in +8% March sales YoY.
  • 👥 Customer Segment: Enterprise segment has 42% higher CLV than SMB. Recommendation: Dedicated enterprise sales team formed → +15% enterprise acquisition.
